The defect: internal/hmacauth/hmacauth.go computed the window as
  skew := v.now().Sub(time.Unix(unixSeconds, 0)); if skew < 0 { skew = -skew }
time.Time.Sub SATURATES at math.MinInt64 for a far-future argument, and
negating math.MinInt64 in two's complement yields math.MinInt64 again —
still negative — so 'skew > MaxSkew' is false and the request is ACCEPTED.
The timestamp window is the ONLY replay bound at M0, so a request signed
once with a far-future timestamp was a credential that never expired.
